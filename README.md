# Adidas-Sales-Performance-Dashboard-in-Power-BI
Built an interactive Adidas Sales Performance Dashboard in Power BI

Situation: Sales data was spread across regions, retailers, products, and sales methods, making performance harder to interpret quickly.

Task: Create one clear dashboard that highlights overall performance and the key drivers behind it.

Action: I built a Power BI dashboard with dynamic KPIs, monthly Sales vs Profit trends, regional analysis, Top 5 retailers, sales-method contribution, interactive filters, and automated Performance Insights using DAX.

Result: The dashboard makes it easier to identify where sales are coming from, which retailers and regions are performing best, and how profitability is changing.

Good dashboards don’t just show data — they make decisions easier.
